## 바꾼 공통 부분

기존 `soc-investigate`에 판단 메타데이터 형식 절을 두고 assessment·basis·evidence_tools의 필수값/길이·현재 실행 인용·상태 관계를 모았다. 본문의 중복 제어 줄 규칙과 코드 안의 불완전한 필드 안내는 이 절을 참조한다. 정정 진단은 실제로 모순된 두 값만 짚고,어떻게 작성하는지는 같은 스킬을 읽는다. 새로운 스킬·도구·포트·권한·재시도 확대는 없다.

이 후보는 [R1 사건 완료 조건](../incident-completion/README.md)을 상속한다. root의 사건별 완료 요건·SDK 일반 조사 검사·빈 설명 검사,canonical에 이미 있는 미적용 읽기 감사/식별자 수정이 포함된다. **전체 후보14파일은 정본/초기 설치/운영에 반영하지 않았다.** R1의 렌더링 미리보기는 옛 gate SHA에 결속돼 있어 R2 배포본으로 재사용할 수 없다. 정확 적용/원복 묶음과 운영 승인·새 실제 채팅은 준비·실행하지 않았다.
