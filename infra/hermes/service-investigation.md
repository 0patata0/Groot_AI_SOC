# 서비스 원인·현재 영향 조사

2026-11-09 후보 검증 중. 운영 적용 및 양봇 새 채팅 검증은 아직 완료하지 않았다. [현재 상태](../../STATUS.md)를 우선한다.

## 확인한 문제

“A 서버의 Vector 오류는 왜 난 거고 지금 로그 수집에도 영향이 있어?”라는 실제 새 채팅에서 Ollama는 journal을 조회하지 않고 과거 답변의 상태와 다른 호스트의 agent를 현재 근거로 답했다. Hermes는 실제 읽기를 수행했으나 필요한 서비스 journal과 수집 지표까지 조사하지 못했다. 각각76.319초·145.851초이며 둘 다 실패다.

서비스 원인을 묻는 짧은 이름이 등록 unit에 연결되지 않았고, SDK의 조사·완료 검사 일부가 서비스 근거를 확보한 뒤에도 일반 경보 조회를 요구했다. 또한 오류 표본0건과 프로세스 active를 수집 기능의 정상으로 확대하는 의미 오류가 있었다. 하네스·도구 경로 오류와 모델 판단 오류를 구분한다.
