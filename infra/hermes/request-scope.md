## 보완한 경로

사용자가 명시한 등록 서비스의 현재 상태·사건 구간 오류를 기존 필수 읽기 묶음에 포함한다. 사건 시각은 root 제어기가 원래 사건에서 만든 정확한 KST 범위이며, 후속 관찰 구간이나 모델이 추측한 시각으로 대체하지 않는다. 모델이 현재 nonce에 결속된 조회 번호를 선택해야 Native MCP가 실행한다. 최대8개씩 선택하고 남은 조회는 다음 묶음으로 넘긴다.

이 기능은 명시적 `c:apache`, `a:vector` 등의 canonical 단위와 현재/과거 요청에 한정한다. 별칭·불명확한 요청·부정/충돌 문장·등록되지 않은 대상은 일반 모델 조사 경로에 남는다. MCP의 실제 이력 지원 단위25개를 사용하며, 서비스 이름을 임의의 셸 명령으로 바꾸지 않는다. 새 자동 판단·승인·쓰기·sudo 권한은 없다.

Hermes의 API용 schema sanitizer는 최상위 `allOf`를 제거한다. 이 때문에 첫63 후보는 raw SDK/registry 검사와 달리 실제 요청에서 추가 조회2개를 놓쳤다.64는 현재 허용된 도구 이름의 **등록 registry 원본**에서 capability를 읽고, 실행은 현재 API 도구 목록·MCP 전 검사·실제 인자로 검증한다. 마지막 누락 검사도 같은 원본 규격을 사용한다. 전송 규격에 없는 도구를 새로 추가하지 않는다.

알려진 operation ID를 rule-change ID나 다른 서버 조회로 선택하는 경우를 응답 schema에서 제외한다. 올바른 종류의 같은 ID와 아직 알려지지 않은 ID는 원래 규격대로 조회할 수 있다. 기존 실행 전 거절도 유지한다. schema 통과가 모델 판단의 정확성을 의미하지는 않는다.

실제로 전송한 실패 조회는 시도로 기록해 무한 재시도를 피하되, 실패를 정상 근거로 바꾸지 않는다. 현재 상태·과거 정제 journal 표본·실제 전체 로그·침해 부재는 서로 다른 증거다. [이력 수집의 공백](../mcp/journal-history.md)은 남아 있다.
