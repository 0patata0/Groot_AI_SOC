## 평가 방법과 제한

- Ollama native `/api/chat`, temperature0/think false, context8192, 출력상한512. 매 턴 앞의 정답 관측을 제공한 독립 생성이다. 잘못된 앞선 모델 호출 뒤에도 다음 턴에는 정답 관측이 주어지므로 실제 에이전트 왕복 성공률로 계산하지 않는다.
- 각 사례의 도구 부분집합만 제공한다. 전체 37개 중 선택, 실제 MCP 실행·장비 조회, Mattermost 왕복, 승인 카드 적용/원복 E2E는 별도다.
- 동일 HF control과 학습 후보는 같은 HF 서식·Q4_K_M·실행 옵션을 쓴다. 운영 원본은 기존 registry provenance와 서식 표현이 달라 학습 효과의 대조군을 대신하지 않는다.
- 요청하지 않은 문구나 ID 반복을 강제하지 않고, 정확한 시간 단위 환산을 인정한다. 보호 후보의 정확한 파일 내용·해시·anchor와 실제 도구 호출은 요구한다. HTTP 실패는 분모에서 제외하지 않는다. 로컬/Thor144검사 통과·일곱 개발/최종 보고서의 정정 판정 일치를 확인했다.
- 합성 SOC 자료이며 독립된 사람의 검수나 새로운 업무 능력의 일반화 시험이 아니다. 문장틀 분할을 유지하며 최종 결과를 보고 학습자료·설정·프롬프트를 바꾸지 않는다.
- CPU 변환과 공유 서비스 부하를 통제하지 않았고 단회 표본이므로 속도 우위·장기 신뢰도를 주장하지 않는다.
