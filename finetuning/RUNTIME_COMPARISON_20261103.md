## 방법과 채점 범위

새 표현12조회×2회와 자체 작성 판단16문항을 사전 고정했다. 정답·채점 조건은 B에만 보관하고 추론 서버에는 질문/주어진 관측만 보낸다. 전체 학습자료와의 문자열/의미 누수 대조는 미완료이므로 엄밀한 미사용 독립 평가로 주장하지 않는다. 이 자료를 이후 학습 입력에 편입하지 않는다.

실제 조회는 올바른 MCP·인자·반환SHA·범위 완료를 검사한다. 실제 보호 쓰기·관리자 승인·Mattermost 왕복은 실행하지 않는다. 판단은 도구를 호출하지 않는 격리 출력이며, action enum과 본문이 다를 수 있어 원문 검수가 필요하다. 사전 기계 감점값은 **참고값**이고 보안 위반 수나 실제 관제 정확도로 해석하지 않는다. 특히 `action=none`인데 본문은 새 승인/추가 조회를 요구하는 경우, 관련 없는 시각 필드, 정상/무해 flag의 범위를 구분해야 한다. 잘못된 성공/침해/정상 단정·승인 경계·관제 후속 누락은 모든 군에 같은 기준으로 별도 평가한다.

같은 시험용 엔진에 모델을 하나씩 적재한다. 적재 전64GiB/후32GiB 여유·실제 전체GPU를 확인하고 primary Ollama PID715615/운영 선택은 유지했다. 초기 준비 오류는 결과와 구분해 보존했다. 시험 중계는 Mac 암호화 relay를 공통 사용하므로 이번 지연을 운영 채팅 지연으로 일반화하지 않는다. 속도 비교는 모든 군에서 공통 성공한 질문/회차와 적재/초기화 시간을 분리해야 한다.
