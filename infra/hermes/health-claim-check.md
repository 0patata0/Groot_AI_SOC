## 수정한 오류

실제 모델 답변의 `Apache … 비정상 접근 여부를 확인`에서 `비정상`의 일부인 `정상`을 정상 단정으로 오인해 재작성을 요구했다. 부정 형용사와 명시적 부정 서술을 구분하고, 같은 문장의 별도 긍정 단정은 계속 검사한다. 실제 캡처한 동일 답변을 전후 검사에 넣어 해당 오검출이 사라짐을 확인했다. 이것은 답변 전체의 정확성이나 일정 시간 단축을 입증하는 시험이 아니다.

후속 실제 조사에서 `서비스 정상화 확인`이라는 근거 없는 단정도 발견했다. 한정어 없는 서비스 정상 표현을 검사하고, 검사의 부정 표현 예외를 유지했다. 별도로 시험한 정상화 안내 문구는129초·내용 오류가 확인되어 기존 문구로 복구했다. 그1회로 인과적 성능 저하를 확정하지는 않는다. 부정 문장을 정상으로 바꾸거나 모델의 위험 판단·종결 결정을 대신 생성하지 않는다. 추가 조사·현재 조회 원장·승인/TTL·도구 권한은 유지한다.
