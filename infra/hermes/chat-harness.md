# 두 봇의 공통 하네스

현재 계약은 **soc-chat-contract:1.5.20 / query1.19.15 / soc-review-routing:1.1.4**다. 운영 반영·실제 새 채팅·미완료 범위는 [최신 검증](harness-cleanup.md)과 [현황](../../STATUS.md)을 따른다. 모델은 기존 Thor 원본35B이며 학습본 승격은 하지 않았다.

| 범위 | 공통 기준 |
|---|---|
| 관제 역할 | LLM이 조사·판단·변경안·정확 승인 요청·적용 후 확인을 주도. MCP/worker는 보호 주소·증거·승인·TTL과 고정 작업을 검증 |
| 공동 채널 | 일반 대화·조회는 Ollama, 복합 조사·상관·변경은 Hermes. 직접 태그 우선, 변경은 한 담당자만 준비하고 상대는 읽기 전용 검토 |
| 조회의 미확인 | 누락/실패를 명시하고 같은 담당자가 보고. 단순 partial이라는 이유만으로 다른 봇을 자동 호출하지 않음. 사건·보호 변경·명시 검증과 예외 보호 호출은 교차 검토 유지 |
| 짧은 요청 | FW/WAF/IDS/Wazuh를 구분하고 대상이 없으면 한 번 확인. 같은 사용자/대화의 읽기 대상만 계승, 새 대상·쓰기·승인은 계승하지 않음 |
| 읽기 범위 | 기본/커스텀을 명시하지 않은 규칙 조회는 전체 범위. 파일 정의·실행 엔진 적재·실제 탐지/차단을 구분. 부족한 근거는 현재 MCP로 확인 |
| 출력 | [soc-output 단일 스킬](skills/soc-output/SKILL.md)을 일반 답변·자동조사·정기 카드·교차 검토가 재사용. 표·근거·미확인·승인/적용을 구분 |
| 지연 | 일반 채팅은 기존 reasoning off. 공동 채널의 기존 FW/고정 진단 빠른 조회 유지. 일반 Hermes 조회의 저추론/서버 축소 후보는 실조회 누락으로 채택하지 않고 읽기 전용·기존 추론 프로필 유지. 사건/peer/쓰기 판단을 낮추지 않음 |
| 사용자 경험 | 명시적 서식 선호만 기록 후보로 사용. 비응답을 동의로 보지 않고 라이브 사실·권한을 사용자 취향으로 저장하지 않음. native skill_manage의 실제 제한 연결은 아직 미완료 |

차단은 기존600초 임시 차단·관리자 카드 승인부터60분 유지·정확 해제 승인 또는 만료·실제 해제/원기한 뒤60초 재차단 대기와 새 증거 조건을 유지한다. 일반 sudo/Docker/임의 셸·패키지 권한을 LLM에 위임하지 않는다. 이미 실행했거나 결과가 불명확한 보호 작업을 자동 재실행하지 않는다.

과거 버전/시험 점수는 [정리 전 원문](../../archive/chat-harness-before-cleanup-20261104.md)에 보존한다. [단문](short-read.md) · [FW 범위](firewall-scope.md) · [긴 표/페이지](chat-table-chunks.md) · [모델3군 비교](../../finetuning/RUNTIME_COMPARISON_20261103.md). 현재 하네스로 모델3군을 다시 평가한 결과는 아니다.
