# 짧은 조회와 실제 근거 — 2026-11-07

학습본·운영 원본을 같은 실제 MCP에 연결한 시험에서 일부 짧은 질문이 구조화된 읽기 경로를 벗어났다. 이 경로에서 도구를 호출하지 않고 차단 IP·룰 ID를 답하거나, 조회하고도 FW 포트의 용도를 잘못 설명했다. [시험 조건·결과](../../finetuning/RUNTIME_COMPARISON_20261107.md)를 보존한다. 모델 학습 성과와 공통 하네스 수정을 구분한다.

## 공통 수정

| 요청/경계 | 처리 |
|---|---|
| `FW 정책 표로`, `방화벽 정책 좀 볼래?` | 명시적인 현재 조회만 전체 FW 읽기 후보로 제한한다. 같은 snapshot의 모든 페이지를 확인한 뒤 표를 만든다. |
| `Wazuh 상관분석 룰 첫 5개만 표로` | 장비·기본/커스텀 범위·상관 필터·요청 상한을 실제 도구 스키마와 반환값에 묶는다. 첫 1~100개만 단순 조회로 처리한다. |
| `지금 임시로 차단된 주소 있어?` | 현재 `list_blocks` 읽기 후보로 처리한다. 과거·해제·원인 조사·다른 장비가 섞인 요청은 이 경로로 축소하지 않는다. |
| 조회 없는 차단 표·가짜 도구 반환 표본 | 실제 성공한 원문 SHA와 대응 읽기가 없으면 완료 답변으로 인정하지 않는다. |
| FW의 실제 임시차단 집합 | 완전한 FW snapshot의 `inet/capstone_fw/agent_block`, `ipv4_addr` 집합만 차단 목록의 근거로 인정한다. 누락·불완전·다른 집합은 대신 쓰지 않는다. |
| 대상 없는 `룰 표로` | 같은 사용자 문맥에 대상이 없으면 한 번 확인한다. 모델이 임의로 장비를 고르지 않는다. |

대상·필드·후보 스키마를 좁히는 공통 코드이며 도구 호출 자체는 기존 LLM 선택/실행 경로를 사용한다. 현재 상태를 답하는 표는 실제 MCP 반환값으로 구성한다. 장비의 사실·사건 판단을 고정 정답으로 대체하지 않는다. 일반 분석·비교·변경에는 기존 조사/승인 경계를 유지한다. 이 방어는 모든 자연어 허위 주장을 잡는 보편적 검증기는 아니다.

## 설치와 복구

공통 `chat_contract.py`·`read_contract.py`, SDK `harness.py`, query 플러그인을 같은 원본으로 배포한다. 공통 버전1.5.62/query1.19.118이다. 루트 `deploy.sh`의 기존 SIEM 플러그인 및 SDK 복사·영수증 경로를 유지한다. 새 패키지·이미지·포트·키·권한은 없다. 운영 서버에 초기 설치기를 실행하지 않는다.

운영 반영 전 기존 파일·권한·소유자와 원본 SHA를 보관하고, 두 작업 큐/관리 작업의 유휴 상태에서 교체한다. 독립15분 복구 타이머와 실제 채팅 검증 후 확정 절차를 사용한다. 원본 모델·보호 설정·운영 DB·승인 기록은 보존한다.

## 검증 상태

로컬 회귀에서 정상 안내를 차단하는 오류를 발견해 수정했다. Mac 전체 검사에 없는 `jsonschema` 때문에 생긴 실행 오류·skip은 성공으로 세지 않았다. 기존 Linux 환경에서 공통 후보1,387검사, Native 후속 최종 후보7프로필1,390검사/skip0을 통과했다. 추가 패키지 설치는 하지 않았다.

[현황](../../STATUS.md)을 함께 따른다. 격리 검사와 새 서버 전체 설치·보호 쓰기·실제 공격 대응 성공은 별개다.
