# Hermes 완료 읽기 근거의 비공개 감사 보존

**구현·격리 검증 완료, 운영 미적용 후보다.** 최근 Hermes 실행10건의 완료된 읽기20개가 네이티브 추적에는 있었지만 공동 채널 전달 요약에는 이름·오류·쓰기 여부만 남았다. 부분 보고의 비공개 감사와 교차 검토 입력에는 결과 본문이0개였다. [검증 원장](validation.json) · [현재 상태](../../../STATUS.md).

| 구분 | 기존 | 수정안 |
|---|---|---|
| 네이티브 RPC 완료, 보고 범위 미완료 | 추적에만 결과가 있고 전달 요약에는 본문 없음 | 기존 serializer로 제한한 읽기 감사 필드를 별도 전달 |
| 보고 범위의 `evidence`가 이미 존재 | 일부 미완료 검토의 감사에는 요약만 남음 | 같은 본문을 IPC에 다시 붙이지 않고 비공개 감사에 보존 |
| 공개 답변·일반 작업 요약 | 원문 본문을 넣지 않음 | 동일. 감사 원문·기각된 초안은 공개하지 않음 |
| 과거 값·승인 재사용 | 완료된 허용 읽기만 기존 기준으로 저장 | 감사 자료는 `reusable_evidence:false`; 재사용·승인 범위 유지 |

## 변경·초기 설치·복구 범위

변경은 `infra/hermes/review_channel_worker.py`와 `review_channel.py` 두 파일이다. 기존 `deployment/review_chat.py:SOURCES`의4파일에 이미 포함되어 `deploy.sh` 초기 설치 경로에도 같은 소스가 들어간다. 새 패키지·TCP 포트·MCP 도구·권한 위임은 없다. 작업자는 같은 고정 묶음의 전달기에서 비공개 serializer 정의만 가져오며 API 클라이언트·서비스 루프는 실행하지 않는다.

전달기는 run/case 일치·등록된 verify 읽기·쓰기/보호 작업 제외·본문 SHA를 다시 검사한다. 기존 제한인32호출, 인자8KiB/호출, 본문256KiB/호출, 감사 전체1MiB·최근200작업을 재사용한다. 과대·변조·누락은 사유와 가능한 해시/크기만 남기며 원문이 있는 것처럼 만들지 않는다. 영수증 생성 실패는 오류 종류만 보존하고 확인한 응답 전체를 성공으로 바꾸지 않는다.

canonical 작업자에는 앞서 승인 대기인 [내부 식별자 제거](../peer-ids/README.md)도 포함돼 있다. 이 두 파일을 그대로 배포한다면 **식별자 제거+읽기 감사 보존을 합친 정확 후보**로 승인받아야 한다. 옛 식별자 전용 `apply_b.py`에 새 작업자를 넣으면 후보 SHA 불일치로 거절된다.

운영 적용 전 현재 source/receipt SHA·모델·정책·큐를 다시 대조하고, 두 소스와 영수증의 비공개 백업·독립 원복 타이머를 준비한다. 전달기는 상주하므로 **작업이 없는 시점의 서비스 재시작이 필요하다.** 승인 없는 적용·진행 중 작업 강제 종료·운영 DB/대화 삭제는 하지 않는다. 적용 후 실제 새 채팅에서 감사 행·공개 출력·상태를 대조하고 확정해야 한다.

## 남은 연결

이 수정은 완료된 읽기를 잃지 않는 **보존 단계**다. 아직 비공개 감사 자료를 교차 검토 입력에 연결하지 않았다. 이후 같은 요청의 조회 범위·시각·대상과 원문 주장에 결속해 전달하되, 과거 값을 현재 상태나 다른 요청의 증거로 재사용하면 안 된다. 의미 검증기와 원문 분리 방식은 [별도 개발 비교](../peer-source-first/README.md)에서 오류가 남아 기각했다. 새 채팅·독립 의미 평가·장기 안정성을 통과한 것으로 보지 않는다.

## 과거 조회 범위 연결 후속의 보류

[연결 후보](../peer-source-context/README.md)는 같은 요청의20읽기·160범위 필드를 전달하고 Mac/B Linux125검사를 통과했다. 그러나 새6사례에서 답변 생성은 양쪽3/6으로 같고 범위 대조 오류가 남아 채택을 보류했다. 후보는 패치로 보존하고 canonical·설치 입력은61733a1로 복구했다. 위113검사 보존 후보와 후속125검사 연결 후보·모델 정답률을 구분한다. 운영 적용/새 채팅은0이며 다음은 역사 출처와 새 관측의 참조 종류를 나누는 보완이다.
