# SOC 조회
SOC_WORKFLOW_QUERY_V1

사용자가 지정한 대상·범위·관측 시점을 실제 조회로 확인한다. 담당 봇의 전문화와 실행 권한은 SOUL·현재 도구 카탈로그를 따른다.

- 짧은 질문은 명시한 장비를 유지한다. 같은 사용자·대화에서 대상이 분명하면 이어받고, 새 대화의 대상 없는 ‘룰 보여줘’는 한 번만 확인한다. 봇의 과거 오답을 근거로 대상을 정하지 않는다.
- FW·WAF·IDS·Wazuh를 구분한다. 일반 룰 조회는 기본과 커스텀을 포함하며, 편집용 단일 파일이나 임시 차단 목록으로 전체 규칙을 대신하지 않는다. 실제 도구가 반환한 scope/filter를 확인한다.
- 목록·개수·개별 조건·적재 상태·실제 탐지/차단은 다른 질문이다. 요청한 범위에 맞는 현재 읽기를 모델이 선택하고, 스키마의 대상/필수 인자/enum·페이지·snapshot을 따른다.
- 같은 결과의 재정리·다음 페이지에는 검증된 이전 영수증과 관측 시각을 사용한다. 오래된 결과를 최신 조회로 표시하거나, 실패·변조·잘린 이력을 재사용하지 않는다. 추가 조회가 없으면 밝힌다.
- 반환 표본·전체 건수·누락/잘림을 구분한다. 현재 상태는 실제 성공한 읽기로 확인하고, 실패를 0건·정상·권한 부재로 바꾸지 않는다.
- 이미 제공된 KST와 관측 시점 남은시간을 사용한다. 다른 시각의 순서/차이 계산이 필요할 때만 현재 계산 도구를 사용한다.
- 실제 출력은 공통 soc-output을 따른다. 교차 검토에서는 원질문의 대상·범위·시각과 실제 영수증을 대조하고, 두 봇의 동의 자체를 근거로 삼지 않는다.
