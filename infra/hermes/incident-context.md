# 사건 시각과 자산 근거의 결속 — 2026-11-03 KST

짧은 웹 시험 뒤 자동조사가 미래 종료 시각으로 조회를 거절당하고, 다른 시각의 탐지 룰을 현재 사건에 섞거나 수집 에이전트 이름을 공격자 이름으로 쓰는 문제가 있었다. 과거의 실제 실행 오류와 보고서는 보존한다. 모델 학습·크기 변경으로 해결한 항목이 아니다.

## 처리와 권한

| 항목 | 변경 |
|---|---|
| 조회 안내 | 실제 사건의 출처·출발 IP·경보 시각에서 분 단위 since_kst/until_kst를 만들고 요청 시각 이하로 제한한다. UTC 입력도 KST로 정규화한다. max16·잘림/조회불가를 명시한다. LLM이 실제 도구를 선택·호출한다 |
| 시간 인자 | 명시 시작/종료와 lookback_minutes를 중복 사용하지 않는다. 과거 분 구간을 미래로 올려 잡던 별도 안내를 제거했다. 계획 자체는 조회 영수증이 아니다 |
| 정정 조회 | 정확한 until_kst 검증 거절만 회복 후보로 추적한다. 동일 도구·그 외 필터로 실제 해당 사건 행을 반환해야 회복한다. 실패 감사 is_error=1은 유지하며 0건·다른 IP·backend/권한/쓰기 실패를 회복으로 간주하지 않는다 |
| 시간/룰 결속 | 반환 경보별 KST·출발/목적 IP·센서 룰을 보존한다. 명시한 한 사건 구간 밖에만 있는 SID를 그 구간의 탐지라고 서술하면 정정한다. 과거 배경·미확인·인용·모호한 날짜는 무리하게 재작성하지 않는다 |
| 자산 이름 | 실제 get_wazuh_agents의 Agent ID/Name/IP를 읽는다. agent는 수집 센서이며 출발 호스트 이름이 아니다. 등록 IP가 일치하지 않으면 해당 센서명을 출발 IP에 직접 붙이는 주장을 정정한다. 등록 IP를 전체 인터페이스 목록으로 보지 않는다 |
| 정상/부재 주장 | “시간 밖 경보 혼입 오류가 없음”은 경보 부재 주장과 구분한다. 같은 문장 뒤에 공격 부재를 덧붙이면 계속 검사한다 |
| 실행 경로 | 자동 관리의 오래된 내장/파일 gate와 두 봇 공통 grounding을 같은 canonical 소스로 맞췄다. query-completion 1.19.10의 SHA 핀도 갱신한다 |

이 검사는 명시적인 일부 근거 결속을 확인하며 자연어 전체의 사실성을 증명하지 않는다. 사건 분류·위험 판단·변경 제안은 계속 LLM의 역할이다. 실제 조회 없이 고정 답변이나 자동 정상 판정으로 대신하지 않는다. 기존 보호 주소·600초 임시차단·관리자 카드 유지/해제·60초 재차단 대기·일반 sudo/Docker 위임 금지를 유지한다. review 담당의 기존 승인형 unblock_ip는 기존 신뢰 플래그 경계에 한정하며 자동 조사/verify에 해제 권한을 추가하지 않는다.
