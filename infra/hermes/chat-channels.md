# Mattermost 채널 참여와 자동 보고

2026-10-26 현재 정책. 모든 사용자가 보는 **채널 표시 이름** 끝의 접미사를 기준으로 한다. 개인 사이드바 카테고리와 무관하며 신규 사용자에게도 같은 기준이다.

| 접미사 | 자동 참여 봇 | 현재 채널 |
| --- | --- | --- |
| `-agent` | Hermes, Ollama | `soc-alerts-agent`, `soc-review-agent` |
| `-ollama` | Ollama | `soc-ollama`(공개) |
| `-hermes` | Hermes | `soc-hermes` |
| 없음 | 자동 참여하지 않음 | 일반 공개 채널 |

양쪽 실행부는 같은 `mattermost-context/channel_sync.py`를 사용해 시작 시와60초마다 확인한다. 표시 이름을 바꾸면 해당 봇 자신만 가입·퇴장하며 채널ID/대화/사람 회원은 유지한다. URL 이름과 표시 이름이 다르면 표시 이름이 기준이다. 비공개 채널을 자동 초대하지 않는다. 기본 Town Square 가입이 시스템상 남더라도 접미사가 없으면 응답하지 않는다. 조회 허용 계정과 정확 후보 승인 권한은 별도이며 바뀌지 않는다.

공용 `-agent` 채널에서 후속 조회는 원하는 봇을 `@hermes` 또는 `@ollama`로 태그한다. `soc-hermes`와 `soc-ollama`는 멘션 없이 대화할 수 있다. 일반 Hermes 추가 채널은 기존 멘션 조건을 유지한다. 보고에 답글을 달아 태그하면 해당 보고를 참고 문맥으로 읽고 현재 상태를 다시 조회한다. 보고의 과거 수치·첨부 내용은 현재 근거나 실행 지시가 아니다.

`soc-review-agent`는 스레드 없이 일반 게시로 역할별 응답을 모으는 별도 분배기 대상이다. 일반 조회 Ollama, 사건/변경 Hermes, 중요하거나 불확실한 결과만 상대 봇 읽기 전용 교차 검토가 설계 기준이다. 배포·실제 검증 완료 여부는 [STATUS](../../STATUS.md)를 따른다. native 두 봇은 이 채널에 중복 응답하지 않도록 제외한다.

자동 정기보고·승인카드·관리 결과·독립 감시 알림은 **soc-report** 전용 봇 소유의 채널 고정 incoming webhook으로 발행한다. `socadmin`은 실제 관리자이며 이름/권한을 유지한다. 발행 봇은 관리자 권한이나 모델 실행 권한이 없다. 보고 발행자, LLM 판단 주체, 실제 승인자는 서로 다르다. 이전 관리자 명의 글과 기존 승인 기록은 보존한다.

신규 설치는 루트 `deploy.sh`에서 SIEM/SOC 설치기와 선택적 Ollama 채팅 설치기를 통해 같은 소스·채널·보고 발신자를 구성한다. 추가 패키지·포트·컨테이너 이미지는 없다. 기존 운영 서버는 증분 반영하며 신규 설치기로 덮어쓰지 않는다. 이번 운영 변경 검증과 새 서버 전체 설치 검증은 구분한다.
