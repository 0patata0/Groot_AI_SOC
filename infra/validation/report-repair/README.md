## 문제 (11/13 23:12 공동 채널 Hermes 조사, B 대화 DB의 초안 3개)

조회는 정확했지만(ModSecurity·Wazuh 2건, 오류 0), 보고서가 정정 2회 후에도 `sample_zero_presented_as_absence`·`missing_or_invalid_management_status`에 걸려 "판단 미완료" 대체 문구로 끝났다. 오늘 같은 질문에서 반복됐다. 실제 검사 함수로 세 초안을 줄 단위로 다시 돌린 결과는 이렇다.

| 초안 | 걸린 문장 | 판정 |
|---|---|---|
| 1차 | "WAF(ModSecurity)는 최근 30분 경보가 없었음", 판단 줄의 "ModSecurity 경보 0건", 표 제목 "### Wazuh 경보 내용 (10건 중)" | 앞의 둘은 실제 위반이다. **표 제목은 검사기 오탐**이다 |
| 2차 | "### Wazuh 경보 상세 (10건 중)"뿐 | **검사기 오탐만으로 실패**했다. 본문은 올바르게 고쳐져 있었다 |
| 3차 | 정정 경위 머리말 "(1) '0건'을 정상으로 서술하는 방식…", 같은 표 제목 | 머리말은 위반(출력 스킬의 "정정 답변은 고친 결과만"을 어김)이고, 표 제목은 오탐이다 |
| 세 초안 모두 | `MANAGEMENT_STATUS: resolved` 다음 줄에 `INCIDENT_DISPOSITION` | 상태 줄이 마지막 줄이 아니어서 무효가 됐다 |

원인은 세 가지다.
1. **검사기 오탐**: 정규식 `0\s*건`에 숫자 경계가 없어 "10건"의 "0건"을 "경보 0건"으로 읽었다.
2. **정정 요청이 무엇이 틀렸는지 말하지 않음**: 정정 요청은 문제 코드만 나열했다. 실제로 걸린 문장과 상태 줄의 구체적 문제는 계산해 두고도 모델에 보내지 않았다. 그래서 모델은 "MANAGEMENT_STATUS 줄 부재"로 오해하고 같은 순서를 반복했다.
3. **제어 줄 순서 안내 불일치**: 컨트롤러 사건 조사 프롬프트는 "MANAGEMENT_STATUS 앞에 INCIDENT_DISPOSITION"이지만, 공동 채널 조사에 붙는 SDK 안내는 "공개 보고 뒤에 INCIDENT_DISPOSITION"이라고만 했다. 스킬에는 순서 규칙이 없었다.

## 수정 (강제 경계·진단은 코드, 원칙은 스킬)

| 위치 | 변경 |
|---|---|
| 관리 실행기 검사기 | 표본 0건 검사의 `0\s*건`을 `(?<![0-9])0\s*건`으로 바꿨다. 실제 부재 주장("경보가 없었음", "경보 0건")은 그대로 거절한다 |
| 관리 실행기 정정 요청 | `management_status_problem`이 상태 줄이 무효인 정확한 이유를 말한다(없음·여러 개·허용 밖 값·뒤에 INCIDENT_DISPOSITION 줄 또는 다른 내용). `rejected_report_lines`는 초안에서 그 문제를 **혼자서도 재현하는 문장**을 최대 4개 찾는다. 정정 요청 끝에 이 진단과 "정정 경위·오류 코드 설명 없이 고친 보고서만"을 붙인다. 진단은 모델 자신의 초안 인용이며 새 근거나 지시가 아니다 |
| `soc-investigate` 스킬 | 제어 줄 순서를 한 줄 추가했다. 두 줄이 모두 필요하면 `INCIDENT_DISPOSITION`을 먼저 쓰고 `MANAGEMENT_STATUS`를 응답의 맨 마지막 줄로 둔다(사용자 지시: 원칙은 스킬로) |
| SDK 안내(하네스) | "공개 보고 뒤에"를 "공개 보고 뒤(실행기의 MANAGEMENT_STATUS 줄이 있으면 그 바로 앞)에"로 고쳐 스킬·컨트롤러와 맞췄다 |
| query-completion | 실행기 SHA 고정값 |

검사 기준은 완화하지 않았다. 실제 부재 주장과 무효 상태 줄은 계속 거절한다. 제어 줄 순서를 실행기가 대신 바로잡지도 않는다(모델 출력 변조 없음).

**실제 초안 재생(로컬)**: 수정 후 2차 초안의 표본 0건 오탐은 사라지고, 남은 문제는 순서 하나다. 그 내용("MANAGEMENT_STATUS 줄 뒤에 INCIDENT_DISPOSITION 줄이 있습니다…")이 정정 요청에 그대로 들어간다. 3차 초안에서 머리말을 빼고 순서만 바꾸면 모든 검사를 통과한다. 1차 초안은 실제 위반 문장 두 개를 정확히 지목한다.
