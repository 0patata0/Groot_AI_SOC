## 공통 요소와 검사

- `read_contract`의 호스트 표기를 진단·인벤토리·객체 상세·Wazuh 자산·후속 질문이 공유한다. 명시 호스트에 없는 서비스는 미지원이며 다른 호스트 기본값으로 바꾸지 않는다. unit·경로·주소·소문자 영문 관사는 짧은 호스트로 읽지 않는다.
- 시간의 표시와 계산을 구분한다. 유효한 `+09:00`·`+0900`·`KST` 제공값만 보수적인 공통 표시기에 맡긴다. 서버 요청·원인 판단·알 수 없는 조건·JSON이 섞이면 이 빠른 표시 경로를 사용하지 않는다. 차이·경과·정렬·실제 시간대 변환은 기존 계산 도구를 유지한다. Native와 SDK가 같은 표시기를 쓴다.
- 조사 안내는 기존 `soc-investigate`의 절로 모았다. 도구 전체 이름을 실제 관측에 추가하고 `workflow_contract`의 절 로딩으로 정정 단계에서도 재사용한다. 잘못된 인용을 코드가 자동으로 바꾸거나 정상 판단을 대신하지 않는다.
- 공식 Harness² `6868817518876de8fd170c6a8354daca273b6191`: 실제24구성+감사용 색인1, 스킬5·스크립트18·수정8면, 상시 문자 증가0. 색인은 시험용이며 운영 프롬프트에 주입하지 않는다.
- 최종 로컬321검사(새22+기존SDK106+Native181+스킬/범위12), B 기존 실행환경의 새22검사 모두 실패/생략0. 같은321개를 기존19파일 후보와 합친 별도 사본에서도 통과했다. 반복 검사를 독립 문항으로 합산하지 않는다.

기존19파일 후보와의 병합은 스킬과 절 목록2곳에서 겹쳤다. **격리 사본에서만** 절을 합친 뒤 공식 구조 검사와 회귀를 했다. 기존 정확 계획·root PREPARED 폴더·승인 범위는 바꾸지 않았다. 이 병합 사본은 새 운영 릴리스나 승인된 확장안이 아니다.

## DNS 잔여 결함

기존본은 `evidence_tools`에 짧은 이름을 써 실제 성공한 읽기 인용을 거절당했다. 후보 초안은 전체 이름을 인용했지만, 공통 검사가 ‘표본0은 전체 부재를 증명하지 않는다’는 부정문을 부재 단정으로, 추가 WAF/ModSecurity 조사 계획을 현재 미조회 사실 주장으로 거절했다. 반복 정정 끝에 안전한 미완료 표로 끝났다.

별도로 모델이 DNS에 무관한 WAF 확인을 권하고 `MANAGEMENT_STATUS: unresolved`라는 허용되지 않은 상태를 만든 문제도 있다. 검사 오탐과 모델 오류를 구분한다. 근거 검사를 느슨하게 하거나 예외 문구로 피해 해결했다고 하지 않는다. 다음 단계는 문장·부정·조건·계획과 실제 사실 주장의 구별, 필요한 추가 읽기 선택 및 유효한 상태 형식의 회귀/실제 생성 검증이다.

## 재현과 운영 경계

정본/설치 입력은 그대로다. `candidate.patch`는 동결된8소스의 **격리 검증 자료**이며 운영 배포 스크립트가 아니다. root용19파일·journal9코드의 기존 승인을 이 후보의 승인으로 해석하지 않는다. 채택하려면 새 라이브 대조·정확 적용/복구안·승인·실제 로드와 두 봇의 새 실제 채팅이 필요하다. 초기 설치기 경로·도구·권한·TTL·의존성은 변경하지 않았다. 새 OS 전체 설치도 미수행이다.

`reproduce.py`는 로컬에 보존한24구성의 비밀 값 없는 읽기 스냅샷과 Git 소스를 이용해 프로젝트 밖의 새 디렉터리에 기존본/후보를 복원하고 공식 구조를 검사한다. 설치된 controller1개는 Git 정본과 같은 바이트가 아니므로 라이브 스냅샷 없이 같은 기준본이라고 가정하지 않는다. 하위 명령은 기존 Python/Git만 사용한다.

```sh
python3 -B infra/validation/common-read-contract/reproduce.py --repo "$PWD" --observed /path/to/live-snapshot.json --output /private/tmp/soc-read-check
SOC_CONTRACT_ROOT=/private/tmp/soc-read-check/candidate python3 -B infra/validation/common-read-contract/test_contract.py
```

스냅샷·실제 반환 원문/해시·초기 실패·정정·격리 병합·정리·결함 우선 검토는 로컬 `대화기록/검증/2026-11-15-common-read-contract/`에 보존한다. 패키지는 설치하지 않았다. 공식 구조 통과·반례 회귀·실제 읽기·실제 채팅은 서로 다른 증거다.
