## 후보

안내 문구와 대상 도구 필터(검증 모드, 허용된 읽기, 64개 이하)는 그대로 두고 **위치만** 바꾼다.

- 시스템 메시지는 실행 내내 바이트 동일하다.
- 목록이 바뀐 시점에 대화 그 위치에 사용자 역할 메모로 한 번 넣는다. 같은 프로세스의 이후 요청은 이전 메모를 같은 위치에 다시 넣어, 각 요청이 직전 요청을 그대로 연장하게 한다. 마지막 메모가 현재 목록이다.
- 메모는 이 프로세스의 API 요청에만 있고 대화 DB에 저장되거나 도구로 실행되지 않는다. 메모를 넣은 지점의 앞부분이 바뀌면(이력 재작성) 그 뒤 메모를 버리고 현재 위치에 새로 만든다.
- 메모를 넣는 조건은 기존 시스템 안내 조건(대기 중 필수 읽기가 없는 단계)과 같다. 선택 단계 프롬프트, 대기 단계, 도구 목록, 디스패치 검증, 승인 경계는 바꾸지 않는다.
- 이 실행기를 SHA로 고정해 읽어 들이는 채팅 플러그인(`query-completion/__init__.py`의 `EVIDENCE_SOURCE_SHA256`)을 새 SHA로 맞췄다.
