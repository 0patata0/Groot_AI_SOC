## 유지 조건

- LLM이 조사·위험 판단·변경안·승인 요청·사후 확인을 주도한다. 관리자는 보호 변경의 승인/거부를 결정한다. 최초600초·유지 승인60분·해제/원기한 뒤60초와 새 근거를 유지하고 지정 IDS Native 예외를 확대하지 않는다.
- DNS Informational/Bad Traffic 원표지와 실제 추가 행위를 함께 판단한다. Wazuh100112 수정 후보는14조건 PASS이나 정확 카드 만료로 운영 미적용이며 승인 없이 재발급/적용하지 않는다. [근거](../infra/validation/dns-noise/README.md).
- 일반 오류/시간초과도 표로 보고하되 미완료를 정상/해소/실행 성공으로 바꾸지 않는다. 수집 agent는 출발지 이름·실제 목적지 증명이 아니다. 과거 백엔드0행/잘림과 현재 서비스 active는 당시 침해 부재가 아니다.
- Mac→관리자231→A→B/C, Kali 직접·새 시험232. 진행 중인 모델은 관측 시간 초과만으로 재시작하지 않는다. Mac 새 패키지 설치0·자체 임시만 정리·운영DB/승인/채팅/trace/가중치/복구본 보존.
- 초기 설정 진입점은 deploy.sh 하나다. 정책/구성 변경은 canonical source·역할 설치·예제·오프라인 목록/검사·운영 가이드를 같은 단위에서 맞춘다. 이번 변경은 기존 source 복사 경로·고정 의존성을 사용하며 새 패키지/포트/키0다. 신규 설치기로 운영 서버를 덮지 않는다.
- 공식 NCSC/NIS 지침은 부분 대조로 유지하며 기관 준수 인증을 주장하지 않는다. 로그 보존/백업/전체 관리 경로·전 업무 공백은 [운영](../deployment/OPERATIONS.md)과 [신규 설치 준비도](../deployment/INSTALLER_READINESS.md)에 구분한다.
- 완료 단위는 표로 보고하고 STATUS/PLAN/README/로컬 기록을 맞춘 뒤 공개 파일만 자동 커밋·푸시/원격 확인한다. 자격·대화·검증 원문·업무분담·발표/논문·가중치·데이터 압축본 Git 제외. 기존 타 작업은 인수 없이 수정/커밋하지 않는다.

OpenClaw/Harness²·SSL VPN/모바일·GPU 드라이버 장기 원인은 별도 고려사항이다. 현재 사건 조사와 보안 경로의 실전 검증을 대체하지 않는다.
