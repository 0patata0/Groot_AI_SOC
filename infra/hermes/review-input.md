# 복합 사건 보고 지연 후보 비교와 미채택 결정

2026-11-06 query1.19.53/common1.5.32의 과거 검증 기록이다. 현행 후속은 [자동 재조사 보완](automatic-review.md)을 따른다. **두 단계 도구 목록 선택 후보는 운영에 채택하지 않았다.** 현재는 이전의 단일 읽기/보고 선택과 전체 등록 인자 규격을 유지한다. 30초 목표의 실측·미완료 범위는 [검증 원장](review-input.validation.json)·[STATUS](../../STATUS.md)를 따른다. 이전 결과는 [정정 전달·종결 일관성](report-feedback.md)에 보존한다.

## 운영에 남긴 변경

- root 문맥에 이미 결속된 operation의 request_id를 rule-change proposal_id나 다른 서버 getter로 옮기면 실제 MCP 호출 전에 거절한다. 정확한 참조를 모델에 전달하지만 자동 재작성·실행하지 않는다. 미등록 ID의 임의 변환·쓰기 권한 확대는 없다.
- 불필요한 전체 FW/NAT 조회와 빈 웹 구간 반복, 진단 c:apache와 웹 서비스 target의 혼동을 줄이는 지침을 보완했다. 현재 프로세스 active·HTTP200·차단 해제는 각각 앱 정상·공격 성공·위험 해소의 증거가 아니다.
- 기존 웹 근거 검사에서 ‘현재 서비스 정상’·‘서비스 영향 없음’이라는 단정을 보완했다. 반대로 ‘현재 서비스의 정상/비정상 여부는 미확인’·‘정상여부 미확인’을 잘못 거르던 오탐은 수정했다. 실제 잘못된 보고와 올바른 미확인 표현으로 재현 검증했다.
- 현재 turn/nonce·실제 영수증·등록 규격·읽기/쓰기 권한·보호 주소·정확 승인·TTL·Native 반복/시간 예산을 유지한다. 명시적 근거 모순 검사이며 모든 위험판단 정확성을 보장하지 않는다.
