# OS 조회 범위 후보의 실제 모델 검증

**읽기 선택 오류가 남아 운영 후보로 채택하지 않았다.** [대상·범위4소스 후보](../read-target-binding/README.md)를 같은 현재 모델과 SDK 환경에서 실제 읽기 MCP로 시험했다. 앞선840회귀·과거 응답 검출과 별도 증거이며, 두 질문을 양쪽에서 한 번씩 실행한4요청이다. 두 봇의 비교나 실제 Mattermost 채팅 시험은 아니다.

| 질문 | 부모 비교본 | 대상·범위 후보 |
|---|---|---|
| B systemd 오류 로그 좀 봐줘 | 현재 failed-unit snapshot1회. 과거 오류 이력으로 확대하는 초안이 거절되어 부분 답변 | 실제 읽기0회인데 과거 서비스 로그를 생성. 새 검사기가 실제 조회 성공 주장을 거절했고 최종에는 근거 없음을 표시. 읽기 성공으로 채점하지 않음 |
| B vector 어제 오류랑 지금 상태 봐줘 | 현재·과거 정제 이력·수집 상태3회. 제공되지 않은 Type=oneshot 추정이 검사에 걸려 부분 답변 | 같은3가지 실제 읽기와 범위/한계 표를 반환. 기록된 초안 거절·잔여 검사 오류는 없지만 사건 상태 unresolved/partial 유지 |

기록된 모델 완료는13회, 실제 MCP 읽기는7회다. 각2개 개발 질문을 반복한 것으로 일반 정확도나 전체 성능 점수를 계산하지 않는다. 현재 지표는 실제 값이 있었지만 오류 표본은 모두0건이었다. 단위 `LoadState=not-found`·반환 속성과 서비스 기능 정상 여부를 구분한다. 보호 호출·게시·운영 소스/설정/DB·서비스/타이머 변경은0이다.

## 확인한 공통 원인

로그 의도는 현재 상태 전용 경로에서 제외된다. 공통 과거 읽기 계획은 실제 MCP 메타데이터에 등록된25개 unit 매핑만 해석한다. `a:systemd`·`b:systemd`·`c:systemd`는 현재 runtime snapshot이며 과거 journal target이 아니다. 따라서 host를 명시한 systemd 로그 질문에는 필수 읽기 계획·정적 선택 범위·미조회 요건이 생기지 않았다. 실제 B 질문에서 모델이 조회 없이 답한 것을 새 대상 검사기가 막았지만, 실제 읽기를 완료하도록 만들지는 못했다.

현재 등록 스키마를 별도로 읽어 확인했다. 서버 광고49개 가운데 Harness²4개는 기존 정책에서 제외되어 허용 목록은45개다. 도구가 아예 없다는 문제와 특정 target의 현재/과거 기능 차이를 구분해야 한다. 추론 강도·재시도만 높여 해결한 것으로 표시하지 않는다.

## 후속 보완의 조건

1. 공통 계획에서 현재 전용 target·등록 unit 이력·journal 원문·색인 경보를 종류별로 구분하고, 명시된 host/대상/기간을 유지한다.
2. 집계 systemd 로그도 실제 지원하는 읽기 경로를 마련한다. host를 추정한 agent ID나 다른 unit으로 대체하지 않고, 원문과 Wazuh 경보를 서로 다른 근거로 표시한다. 필요하다면 기존 MCP의 고정 host·기간·마스킹·크기 제한 안에서 집계 journal을 확장하되 정확 새 후보로 검증/승인을 받는다.
3. Type·unit·정상 종료는 실제 반환 값이 있을 때만 설명하고, 부재/조건/부정 문장에 대한 검사 오탐과 실제 과장을 각각 회귀한다.
4. 공식 Harness²→후보 동결→회귀→새 실제 읽기/정정→정확 승인·운영 로드·새 채팅을 확인한다. 조회 성공을 위험 판단/종결로 바꾸지 않는다.

위 항목은 **다음 완료 기준**이며 아직 구현·적용하지 않았다. 현재4소스 패치가 운영 준비 완료라는 뜻이 아니다.

## 근거와 보존

[검증 원장](validation.json)에 실제 질문·인자·반환/응답 SHA·초안 거절·시간·분모·한계를 보존했다. 오류가 포함된 원문과 실제 서버 값은 로컬 검증 원장에만 보관한다. 원격 자체 시험 폴더122파일3,458,007바이트는 전체 수집/SHA·모든 PID 종료/부재·운영24소스 불변 확인 뒤 제거했다. 기존 양봇PID·관리 타이머와 원래 두 정확 승인 계획은 유지한다. Mac 자체 임시3,016파일48,172,237바이트와 생성 transport를 제거·부재 확인했다. 원문·framework·자료/가중치·운영 백업과 논문56쪽15파일SHA는 보존했다.

공식 Harness²의 고정 버전·25구성/4수정면/상시 증가0과 양쪽24SHA/AST 복원을 이 시험 전 다시 확인했다. 단순 회귀·거절 검출은 실제 완수의 증거가 아니다. [현재 상태](../../../STATUS.md)·[계획](../../../PLAN.md).
