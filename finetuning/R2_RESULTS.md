# SOC R2 학습·비교 결과

학습과 24/48-step 개발 비교를 완료했다. **미사용 최종 시험의 후보는 24-step이며, 운영 모델은 기존 `qwen3.6:35b`를 유지한다.** 최종·기존 회귀 시험은 진행 중이다. 현재 상태와 Git 영수증은 [STATUS](../STATUS.md)를 기준으로 한다.

## 실제 학습과 복구

- 승인: 공유 Ollama 최대 60분 중단, 자동복구. 실제 중단은 **2026-10-28 11:01:44~11:40:00 KST, 38분 15.87초**다.
- 원본에서 최장 2개 prefix로 2-step 시험 후, 다시 미학습 원본에서 48-step을 실행했다. 이전 퇴행 모델이나 시험 어댑터를 이어 학습하지 않았다.
- train 192대화/390개 가용 prefix, validation 32대화/65개 prefix, final test 32대화/65개 prefix. 48-step은 accumulation 2·최대 96개 prefix 갱신·epoch 0.2461538이며, train 전체 1회 완료가 아니다.
- lr 5e-6, LoRA r16/alpha32/dropout0, BF16, strict 2048. pilot train loss 0.9923964, eval loss 0.8650029. 손실은 정확도가 아니며 자료가 다른 이전 실험과 직접 비교하지 않는다.
- 두 stage exit0, 가중치 380개 텐서 finite/190개 B 행렬 nonzero. peak allocated 70.29/reserved 82.82GiB, host 가용 최저 약32.52GiB. OOM kill은 없었으나 **커널 드라이버 메모리 할당 경고 50건의 원인과 장기 안정성은 미해결**이다.

## 개발 비교: 같은 32대화·65턴

| 모델 | 필수 도구 호출 형식·인자 충족 | v3 자동 제한점수 | 자동 치명 오류 턴 | 주요 수동 확인 |
|---|---:|---:|---:|---|
| 운영 원본 | 27/30 | 94.92 | 1 | exercise_window만으로 Benign 단정, 근거 없는 프로세스 부재 설명 |
| 동일 HF 미학습 control | 27/30 | 94.77 | 1 | 존재하지 않는 변경 anchor, WAF/IDS를 FW 사용자 체인으로 설명 |
| 24-step | 27/30 | 96.46 | 0 | 실패를 미시도로 단정, 제안 후 승인 대기 비명시 |
| 48-step | 27/30 | 95.54 | 0 | 경보 level5를 높은 심각도로 설명, 근거 없는 스캔 가능성·영문 Non-Compromised 표현 |

이 점수는 **일반 정확도나 실제 장비 작업 성공률이 아니다.** 48-step의 `단정하기는 어렵지만`은 불확실성을 명시한 정답인데 v3 정규식이 조사 `는`을 인식하지 못했다. 이 한 건의 오감점을 수동 정정하면 48-step도 96.46이다. 원문·기존 판정은 보존한다. 24-step 선택은 이 점수 차이가 아니라 경보를 더 보수적으로 판단한 원문을 근거로 했다.

모든 모델에서 호스트명을 프로세스 검색어로 잘못 넣는 1건과, 변경 제안 도구 대신 설명만 하는 2건이 남았다. 따라서 **도구 기능 개선이나 운영 준비 완료를 주장하지 않는다.** 48-step까지 학습했다고 항상 더 나은 답변이 나오는 것도 아니다.

## 평가 방법과 제한

- Ollama native `/api/chat`, temperature0/think false, context8192, 출력상한512. 매 턴 앞의 정답 관측을 제공한 독립 생성이다. 잘못된 앞선 모델 호출 뒤에도 다음 턴에는 정답 관측이 주어지므로 실제 에이전트 왕복 성공률로 계산하지 않는다.
- 각 사례의 도구 부분집합만 제공한다. 전체 37개 중 선택, 실제 MCP 실행·장비 조회, Mattermost 왕복, 승인 카드 적용/원복 E2E는 별도다.
- 동일 HF control과 학습 후보는 같은 HF 서식·Q4_K_M·실행 옵션을 쓴다. 운영 원본은 기존 registry provenance와 서식 표현이 달라 학습 효과의 대조군을 대신하지 않는다.
- 요청하지 않은 문구나 ID 반복을 강제하지 않고, 정확한 시간 단위 환산을 인정한다. 보호 후보의 정확한 파일 내용·해시·anchor와 실제 도구 호출은 요구한다. HTTP 실패는 분모에서 제외하지 않는다. 로컬/Thor138검사 통과.
- 합성 SOC 자료이며 독립된 사람의 검수나 새로운 업무 능력의 일반화 시험이 아니다. 문장틀 분할을 유지하며 최종 결과를 보고 학습자료·설정·프롬프트를 바꾸지 않는다.
- CPU 변환과 공유 서비스 부하를 통제하지 않았고 단회 표본이므로 속도 우위·장기 신뢰도를 주장하지 않는다.
