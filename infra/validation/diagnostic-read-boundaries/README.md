## 변경과 보호 경계

전체9개 운영용 소스/스킬과 기존 clock fixture2개가 부모와 다르다. 두 봇은 같은 카탈로그 대상 해석을 사용한다. Native는 turn·현재 요청에 결속하고 SDK는 실제 도구 초기화 뒤 모델 호출 전에 확인한다. 등록되지 않은 호스트, IP 추정, 다중 호스트 요청을 하나의 기본 대상으로 바꾸지 않는다.

이력·journal의 내부 시계는 한 번 캡처한 정수 마이크로초를 사용한다. 기존 정수 초 메타데이터는 유지하고, 공개 MCP 입력에 now/clock을 추가하지 않는다. 30일 보존·단일24시간·미래 금지·20초/child12초·128MiB/Tasks8·마스킹·UID/권한·승인·보호 주소·TTL을 유지했다. 안내는 기존 soc-query/soc-investigate 절에 넣었다. 사건 정상 판정이나 승인 선택을 코드로 대신하지 않는다.

세 실행 모두 partial이며 worker 실행 완료와 품질 완료는 별개다. 실제 SDK4읽기/기록된 모델 완료6회와 별도 프로토콜 성공2읽기·입력 거절3회를 구분한다. 새 대화·새 문장·변한 실제 로그이므로 [이전4요청](../host-journal-model/README.md)과 통제된 속도 전후 비교로 쓰지 않는다. 특히 같은 시각·데이터의 모델 비교, Hermes 실제 요청·Mattermost 게시·A/C 새 실제 시각 조회는 하지 않았다.

Mac18프로필은1,084개 중1,078통과·기존 optional OpenAI6생략, 기존 Hermes 이미지 UID10001/네트워크 연결 금지 시험은1,167개 모두 통과했다. 첫 Linux clock 검사에는 비교용 원본 MCP 파일1개를 빠뜨렸으며 원본 추가 뒤 해당13개만 재검사했다. production 코드를 바꾸거나 실패 검사를 삭제하지 않았다. 회귀 개수를 독립 SOC 사례·정답률로 쓰지 않는다.

## 로컬 복원과 검사

Git 이력, Python3, 보존한 고정 `G_Harness2/`가 필요하다. 새 패키지 설치·네트워크·모델·서버 작업 없이 프로젝트 밖의 새 경로에 복원한다.

  python3 -B infra/validation/diagnostic-read-boundaries/test_clock.py

운영 소스30개·기존 reader PID/ticks·모델/권한 설정을 보존했다. 자체 시험 unit2개는 supervisor가 종료했고 근거 보존 뒤 원격 자체2폴더만 제거했다. Mac 자체13,652파일/207,960,500B·생성transport7개도 소스/근거 보존 뒤 제거·부재 확인했다. 기존 정확19/journal9 승인 계획·백업·논문15파일·다른9작업·G_Harness2·자료/가중치는 유지한다.
