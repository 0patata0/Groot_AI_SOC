## 원인과 변경

- 명시적인 독립 현재 차단 목록 절을 서비스 읽기 계획에 합성한다. 등록된 `mcp__resp__list_blocks`의 빈 인자 규격을 확인하고, 기존 모델의 번호 선택·검증·실제 MCP 실행을 사용한다. 코드가 대신 사건 결론이나 차단 결정을 내리지 않는다.

- 과거·특정 IP 조건·조건부·인용·조회 제외·쓰기 요청을 현재 전체 차단 목록으로 강제 해석하지 않는다. 이 보장은 인식한 독립 현재 목록 절에 한정된다. 임의 복합 문장 전체를 해결했다고 주장하지 않으며 다른 요청은 기존 에이전트 경로를 유지한다.
- SDK의 실제 허용 읽기 카탈로그와 후속 관측 자료에 차단 목록을 포함한다. 자료는 비신뢰 도구 반환으로 표시하고 개수·크기 제한과 생략 표시를 유지한다. 쓰기 결과·잘못된 서버의 동명 도구는 읽기 근거로 편입하지 않는다.
- 미완료 대체 답변에도 확인된 근거표를 남긴다. 유효한 차단 IP는 최대50개를 표시하고 전체 수와 표시 한도를 구분한다. 조회 성공을 위험 판단·복구·변경 성공으로 확대하지 않는다.
