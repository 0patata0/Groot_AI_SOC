## 확인한 불일치와 반영

공통 지침에는 `get_system_diagnostics`가 과거 journal 조회가 아니라고 일괄 서술되어 있었다. 실제 진단 MCP1.2.2는 등록된 systemd 서비스25개의 과거 정제 오류 메타데이터를 지원했다. 현재 조회와 과거 조회를 구분하도록 바로잡았다.

| 구분 | 실제 사용과 한계 |
|---|---|
| 현재 상태 | 시간 인자 없이 해당 서비스의 고정 스냅샷 조회. 수집 시각·나이 확인 |
| 과거 오류 | 같은 서비스 target에 `since_kst`와 `until_kst`를 함께 지정. 최근30일 내·최대24시간·lookback 혼용 금지 |
| 실제 대상 | root 소스의 TARGETS에서25개 `target=unit` 대응을 도구 인자 설명에 생성. 비슷한 이름의 다른 서비스로 대체하지 않도록 안내 |
| 근거 한계 | 과거 응답은 현재 상태를 포함하지 않는다. 부분 수집·publisher_stale·has_more·반환 표본을 확인하며 exit1만으로 상세 원인을 만들지 않음 |

도구 실행·허용 대상 enum·입력 검증·출력·수집·권한은 바꾸지 않았다. 모델이 읽기를 선택하고 판단하는 경로를 유지했다. 일반 셸이나 journal 원문 접근 권한을 추가하지 않았다. 관리 게이트는65,345B로 기존65,536B 상한 안에 그대로다.
