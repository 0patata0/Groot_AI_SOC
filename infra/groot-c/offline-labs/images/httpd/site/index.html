01 / 정상 경로

Alias의 기본 동작

URL과 실제 저장 경로가 서로 다를 수 있습니다. 다음 링크는 의도적으로 공개한 일반 파일입니다.

URL
/lab/alias/hello.txt
컨테이너 내부
/lab/public/hello.txt
공개 파일 열기 ↗
02 / 관찰 대상

무해한 실습 파일

일반 웹 경로 밖에 공개용 표식 파일 하나를 두었습니다. 실제 계정 정보나 호스트 파일은 실습 대상으로 사용하지 않습니다.

/lab/fixture/harmless.txt

표식: GROOT_PUBLIC_TRAINING_FIXTURE
이 파일에는 별도 공개 URL을 연결하지 않았습니다.

03 / 범위와 확인

파일 접근에 집중

CGI 실행 기능과 공격 스크립트는 포함하지 않습니다. 파일 접근 허용 여부와 WAF·서버 로그를 구분해서 확인하세요.

앞단 프록시의 경로 정규화나 WAF 차단 때문에 요청이 이 컨테이너에 도달하지 않을 수 있습니다.
