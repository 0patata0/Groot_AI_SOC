# SOC 결과 보고
SOC_OUTPUT_CONTRACT_V1

조회·사건·승인안·정기 카드·교차 검토는 이 공통 출력 기준을 재사용하며 비슷한 출력만을 위해 스킬을 새로 복제하지 않는다. 사용자가 지정한 형식·상세 범위를 우선한다. 출력 형식은 조회·위험 판단·승인·실행을 대신하지 않는다.

- **조회·목록·로그·상태·규칙을 보여달라는 요청은 단일 장비·한 건도 Markdown 표로 출력한다.** FW/WAF/IDS/IPS/Wazuh, 사건·상관분석, 서버·서비스·journal 모두 같은 기준이다. 기본 열은 `대상 | 결과 | 근거 | 미확인·다음 조치`이며 개별 로그에는 시각(KST)·관측 출발지·대상·룰 ID와 설명·결과를 실제 반환값으로 표시한다. 주소 역할과 실제 요청자, 센서 ID와 Wazuh ID를 구별하고 없는 값은 미확인으로 둔다. 사실·해석·미확인·승인 대기를 섞지 않는다.
- 기본 답변은 핵심 요약 1~2문장과 결과 표다. **상세 요청 때만 필요한 상세 설명을 줄글로 추가하며, 목록·수치·개별 로그는 계속 표로 유지한다.** 개념 설명이나 대상 확인 질문은 1~3문장으로 답할 수 있지만, 짧은 조회 요청이라는 이유로 표를 생략하지 않는다. 요청한 장비·룰·미확인을 줄이기 위한 임의 행/열 제한은 두지 않는다. 일부만 표시하면 전체·표시 범위·생략·다음 페이지를 밝힌다. 조회 실패·반환0건은 상태 표에 범위와 함께 표시하고 가상의 로그 행을 만들지 않는다.
- 표 앞뒤에 빈 줄을 두고 머리글 바로 다음 줄에 `|---|` 구분선을 넣는다. 표를 코드 블록·인용·들여쓰기·HTML로 감싸거나 공백으로 정렬하지 않는다. 셀의 원문 `|`는 escape하고 셀 안 줄바꿈/중첩 표를 피한다. 긴 표는 행 경계에서 나누고 각 메시지에 같은 머리글·구분선을 반복한다. 행·순서·식별자·조건을 보존한다.
- 승인안은 대상·변경 전후·영향·검증·승인 상태를 구분하고 실제 제안 ID/링크를 표 밖에 쓴다. 카드에 이미 게시한 전체 diff/후보는 반복하지 않는다. 제출·승인·적용·사후 확인·원복을 구분한다.
- 사건은 출처·주소/대상·룰 이름공간·사건 시각과 조회 구간·대응 결과를 확인한 근거로 요약한다. 경보 매칭/HTTP403/차단 만료만으로 침해 실패·위험 해소·종결을 단정하지 않는다. Wazuh 규칙 ID를 정의 확인 없이 빈도·시간 상관 룰이라고 부르지 않는다.
- **LLM 사건관리·자동 조사·재검토**도 같은 서식을 쓴다. 첫 문장에 사건과 현재 결론을 쓰고, `확인 항목 | 결과·판단 | 근거·범위 | 미확인·다음 조치` 표로 정리한다. 필요한 행은 사건/대상, 탐지 근거, LLM 판단, 실제 조치·승인 상태, 남은 확인이다. 사건마다 같은 ID·시간·JSON을 여러 구획에 반복하지 않는다. 실행된 조치가 없으면 그대로 표시하고 제안·승인 대기를 실행 완료로 쓰지 않는다.
- 재검토·정정 답변은 정정한 현재 결과와 근거만 보고한다. 이전 오답·오류 코드·같은 사건 개요를 여러 구획에 반복하지 않고 이전 초안은 감사 원문에 남긴다. 출발지 이름을 추정해 빈칸을 채우지 말고 수집 agent 이름과 별도 열로 구분한다.
- **검증 실패 보고**도 긴 근거 목록 대신 `확인 항목 | 조회 결과 | 근거·범위` 표를 쓴다. 센서별 요청 구간·반환 표본/전체 미확인, WAF 룰 ID·Suricata SID·Wazuh 규칙 ID, 요청 상태와 실제 차단 관측을 구별한다. 원문 JSON·제어 필드 설명·중복 시각 목록은 기본 보고에 붙이지 않고 감사 원문에 보존한다. 형식 정리는 근거 없는 판단이나 누락된 조회를 완료로 바꾸지 않는다.
- 실패·부분 조회·도구 미지원은 해당 대상·오류와 미확인 범위를 표시한다. 실패를 0건·정상·권한 거부로 바꾸지 않는다. 필요한 원문/JSON/로그·diff는 상세 요청 때 해당 부분만 별도로 제공하며 감사 원문은 변경하지 않는다. 같은 작업의 반복 조회는 관측 시각을 붙여 비교하고 중복 JSON을 나열하지 않는다.
- 설명은 한국어, 시각은 확인된 KST(+09:00)다. 이미 제공된 KST/관측시점 남은시간을 재변환·암산하지 않는다. 조회·발생·승인·만료 시각을 구분하고 시간대 없는 값은 미확인으로 남긴다. ID·주소·오류·원문·승인 diff는 보존한다.
- 내부 제어 줄은 일반 답변의 표/본문에 출력하지 않는다. 실행기가 요구하는 `INCIDENT_DISPOSITION`·`MANAGEMENT_STATUS`는 지정된 정확 구문·별도 줄로 작성하며 코드펜스·escape·번역하지 않는다. 이 표식은 승인이나 실행 권한이 아니다. 진행 중 표시는 실제 실행 신호를 사용하고 모델이 진행률·완료 시각·처리시간 footer를 만들지 않는다.
