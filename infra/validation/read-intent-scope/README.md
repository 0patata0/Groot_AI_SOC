# 짧은 조회 의도·주제 표본 후보

‘봐줘·볼래·확인해 줄래’의 공통 조회 표현을 보완하고, DNS 경보 요청에 룰 정의가 끼어드는 경로를 분리한 **미적용 개발 후보**다. [앞선 읽기 시도 후보](../read-attempt-binding/README.md)를 재구성한 격리 소스에서만 검사했다. 정본·초기 설치 입력·운영 설치 파일은 변경하지 않았다. 부모 후보가 미해결인 문제까지 해결한 것으로 표시하지 않는다.

| 변경 | 실제 범위 |
|---|---|
| 공통 표현 | `chat_contract.read_action_remainder`를 이벤트 목록과 등록 서비스의 제한 조회 문법에서 재사용. 장비·기간·부정·미지정 조건은 지우지 않음 |
| DNS 목록 | 명시한 DNS 경보/로그의 단순 목록은 Suricata 경보 표본. DNS 질문 또는 signature의 DNS 표기에 맞는 행만 표시. 포트53만으로 분류하지 않음 |
| 건수·표시 | 원래 반환 표본 수와 DNS 관련 표시 수를 구분. 없는 서버 필터를 만들지 않고 전체 DNS/트래픽·공격 부재로 확대하지 않음 |
| 안내 | 기존 `soc-query` 스킬 절을 재사용. OS journal·현재 snapshot·미실행/실패 구분을 안내하지만 해당 OS 서술 오류의 코드 보완은 아직 미완료 |
| 범위 | 3소스만 변경. 역할·쓰기·승인·보호 주소·모델 설정·재시도·실행 예산·Native gate 핀·runtime 변경 없음 |

| 로컬 | 801개 집계795통과/6의존성 생략. 신규16메서드에는 21개 센서/표현 조합과 부정·복합·조건·잘못된 영수증·빈/혼합 표본 반례 포함 |

3건 모두 필요한 경보 읽기만 선택하고 줄글 대신 표를 반환했다. **모두 빈 표본이며, 통제된 전후 비교·독립 SOC 정확도·채팅 왕복 속도가 아니다.** 동시 CPU 검사·모델 캐시/부하·조회 시점이 통제되지 않았다. 양성/혼합 표본의 분류는 fixture 회귀만 확인했다. 현재 사건을 재생하거나 공격을 재개하지 않았다. 모델 digest는 수집 시점에 직전 단위 관측과 같았으며, 이번 시험 직전 새 digest는 확보하지 않았다.

## 남은 범위와 운영 절차

- 대상명만 쓴 OS 가짜 과거 조회 실패·현재 snapshot을 과거 로그로 설명하는 문제, 조사 답변의 표본0 과장·개별 SID 활성 주장은 남아 있다.
- 명시한 WAF/Wazuh와 DNS의 복합 조건·특정 IP·위험/원인 판단은 이 단순 선별로 완료하지 않는다. 실제 도구/조건을 확인하는 조사 경로를 유지한다.
- 실제 Native 대화·양봇 Mattermost 게시/표 렌더·비어 있지 않은 새 근거·동등 조건 회귀를 추가 확인해야 한다. `completed` 자체를 품질 통과로 세지 않는다.
- 기존19파일·journal9 정확 승인 계획은 불변이다. 이 패치·부모 후보는 두 승인 범위에 추가되지 않는다. 운영 채택 시 현재 소스·설치 사본/영수증·설치기 영향·관리자 경유·정확 후보 승인·복구·새 실제 채팅을 별도로 준비한다.
- 자체 테스트 서버2폴더를 수집/전체SHA/종료PID 확인 후 제거했다. 운영 코드/DB/서비스 조작·실제 채팅 게시·공격·새학습0이다. 공식 G_Harness2·기존 승인 대기 백업·자료/가중치는 보존한다.

## 재현

새 출력 경로는 저장소 밖의 일회성 임시 경로로 지정한다. 기존 공식 G_Harness2만 사용하며 패키지를 설치하지 않는다.

```sh
python3 -B infra/validation/read-intent-scope/reproduce.py --repo /absolute/path/capstone_project --output /private/tmp/fresh-read-intent-replay
SOC_INTENT_ROOT=/private/tmp/fresh-read-intent-replay/candidate python3 -B infra/validation/read-intent-scope/test_intents.py
```

[정확 SHA·부모·변경 범위](manifest.json) · [동결 패치](candidate.patch) · [검증 요약](validation.json). 패치는 운영 서버에 직접 실행하는 설치/적용 스크립트가 아니다. 원문/상세시각·현재 소스 관측·영수증/테스트 출력은 로컬 전용 `대화기록/검증/2026-11-15-read-intent-scope/`에 보존한다.

## 대상·view·과거 범위의 후속 검증

[공통4소스 후보](../read-target-binding/README.md)는 OS 대상명·host/unit/container·view·기간과 실제 읽기 시도를 결속했다. 같은 질문의 과거 실제 두arm에서 미실행 과거 조회를 실패로 쓰는 문제를 검출하고 로컬840집계/기존Hermes840생략0·공식Harness²·공개24SHA/AST/신규39재현을 확인했다. 새 생성·실MCP·채팅0이며 운영 미적용이다. 이 결과로 앞선 실제 응답이나 속도 수치를 소급 성공으로 바꾸지 않는다.
