## 현재까지 완료한 단위

11/4 웹 보안 후보는 사용자 정확 SHA 승인 뒤 C→A 순으로 적용·외부 검증·확정했다. UI/API를 포함한 WAF 경유·DetectionOnly 예외 제거·관리자231/32+HMAC 세션 제어, linked WAF 신뢰 SHA 정정과 실제 writer 검증을 마쳤다. [검증·복구·한계](infra/validation/web-policy/README.md). 관리형 HTTP3개는 기존 중지 상태이며 등록 Log4 앱503을 실제 확인했다. 단일 DVWA 실검증은 아래 범위이고 전체 공격/승인 실행·종결은 남는다.

A 관리 SSH·Wazuh443/10443을 관리자231/32·내부 SSH를 MCP B 한주소로 제한한 전일 운영 단위, 새 단문/페이지·공유 차단 참조·사건 구간/센서·만료KST/절차 보완과 공개 PCAP11개 반입/선별 시험은 [STATUS](STATUS.md)의 확인 범위로 유지한다. 기존 실패와 미검증을 성공으로 덮지 않는다.

11/4 룰 감사는 [원문·참조·native 회귀](infra/validation/rule-overlap/README.md)까지 완료했다. IDS 전후14/14·유지 경보9개 동일은 해당 합성 표본의 범위다. Wazuh Windows 미검증을 탐지 실패나 통과로 바꾸지 않는다. 운영 삭제/설정 변경과 신규 설치는 수행하지 않았다.

[Hermes 긴 표와 양쪽 표시 페이지](infra/hermes/chat-table-chunks.md)는1.5.19/query1.19.14로 보완·14:26:57 운영 확정했다. 같은16행을 분할 표로 보존하고 다음3행을 실제 MCP와 대조해 총19개 조건이 일치했다. 새10채팅·서버669검사 통과 범위이며 브라우저 UI·단일 초장문 행은 별도다. 다음은 실제 사건 종결의 근거 연결·보안 경로와 전 관제 업무 공백을 확인한다.

[실제 DVWA 단일 SQLi](infra/validation/web-e2e/README.md)에서 WAF403→Wazuh→LLM4MCP→600초FW/카드→만료·정상HTTP200 복구를 확인했다. 최초 차단 약146.4초·4회 조사 뒤 needs_review/근거 부족으로 종결 실패를 남긴다. 내부 제어 문구 노출만 게시 단계에서 보완·관리209/설치계약37PASS·B한파일15:12:14확정, strict 결정/승인/서비스·모델은 유지한다. 수정 후 새 실제 보고 전달은 별도 미검증이다.

11/4 [하네스 정리](infra/hermes/harness-cleanup.md)를 운영 적용했다. 일반 조회의 Ollama 담당 유지·단일 출력 스킬·짧은 표/정기 카드·증거 요약/누락 센서 재조회 보완과 서버1,048PASS를 확인했다. 실제 새 일반 조회2건은 Ollama 단독16.676/13.019초이며 단순 partial로 자동 peer를 만들지 않는다. 17시대 사건 프롬프트/서버 축소 후보는 실제 MCP 누락으로 제외했다.18:13에는 별도 조회 전용 프롬프트와 낮은 추론을 실제3질문으로 검증해128.644→34.147초 표본을 확인했다. Native discovery·사건/peer/쓰기 판단은 유지한다. [검증·복구](infra/hermes/lookup-latency.md). native 사용자 피드백/skill_manage 제한 노출·실제 새 사건 종결·브라우저 표 UI는 남는다.

## 초기 설치·상품 배포 요구 — 확인만 수행

11/4 사용자는 동일 정책의 최초 설치와 패키지 일괄 설치·상품성을 요청했고, 실제 설치는 지금 하지 말고 확인만 하도록 범위를 정했다. 이번에는 [초기 설치 점검](deployment/INSTALLER_READINESS.md)의 소스 연결·허용 목록·가짜SSH 회귀만 확인했다. 최초 점검 당시 운영/설치 코드 변경·실제 설치0이었다. 이후 하네스의 새 SKILL/공통 로더 소스 복사 경로만 동기화했으며 실제 새 서버 설치는 계속0이다.

제품 배포 완료 조건에는 review 원격 허용목록·기대값 회귀 정리, WAF 증거 초기 준비의 실제 연결, 두 봇/공동 채널/동등 권한의 명시적 프로필, 전체 오프라인 의존성+무결성+설정/검증/복구를 같은 설치 묶음으로 제공하는 항목을 추가한다. 실제 새3VM 초기 설치 시험은 가능하다는 사용자 지시 전 수행하지 않는다. 현재 웹 방어/LLM 전 관제 업무·논문 목표를 이 요구로 대체하거나 완료로 축소하지 않는다.

## 유지할 운영 조건

설정 수정은 Mac→관리자231→A→B/C로 통일한다. 두 Kali는 직접 SSH하며 새 공격·PCAP 시험은232에서만 실행한다. 할당받지 않은 내부 주소를 시험용으로 도용하지 않는다. 관리자/인프라 보호 주소·600초 임시 차단·승인부터60분 유지·정확 해제 승인/만료·60초 cooldown을 유지한다. 지정 IDS Native 선차단 예외를 새 일반 자동차단으로 확대하지 않으며, LLM은 실제 결과를 조사·판단하고 후속 승인을 주도한다.

서버/포트/프록시/보안정책이 바뀌면 같은 단위에서 루트deploy.sh·역할 설치·설정 예제·오프라인 목록·검증/현재 문서를 맞춘다. 신규 설치기 전체를 기존 서버에 실행하지 않는다. 완료한 단위는 표로 보고하고 공개 파일을 자동 커밋/푸시하며 원격 일치를 확인한다. 로컬 대화/검증 원문·업무분담·발표/논문·자격·가중치는 Git 제외다. 실제 운영·공격E2E·새 OS설치·모델 의미 품질을 서로 대체하지 않는다.

OpenClaw·Google Harness²·SSL VPN/모바일 푸시는 후보/검토 범위다. 기본 Qwen3.6-35B-A3B 유지·학습본 승격은 검증 우위 근거가 있을 때만 결정한다. 전체 목표 미완료 상태를 유지하며 예산/시각 때문에 임의 완료나 일시정지로 표시하지 않는다.
