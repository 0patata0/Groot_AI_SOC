## 초기 설치·상품 배포 요구 — 확인만 수행

review 원격 허용목록2작업과 host-check/verify 기대값3을 정정하고 fakeSSH46·허용/거부12조건을 통과했다. 제품 배포 완료 조건에는 WAF 증거 초기 준비의 실제 연결, 두 봇/공동 채널/동등 권한의 명시적 프로필, 전체 오프라인 의존성+무결성+설정/검증/복구를 같은 설치 묶음으로 제공하는 항목을 추가한다. 실제 새3VM 초기 설치 시험은 가능하다는 사용자 지시 전 수행하지 않는다. 현재 웹 방어/LLM 전 관제 업무·논문 목표를 이 요구로 대체하거나 완료로 축소하지 않는다.

## 유지할 운영 조건

설정 수정은 Mac→관리자231→A→B/C로 통일한다. 두 Kali는 직접 SSH하며 새 공격·PCAP 시험은232에서만 실행한다. 할당받지 않은 내부 주소를 시험용으로 도용하지 않는다. 관리자/인프라 보호 주소·600초 임시 차단·승인부터60분 유지·정확 해제 승인/만료·60초 cooldown을 유지한다. 지정 IDS Native 선차단 예외를 새 일반 자동차단으로 확대하지 않으며, LLM은 실제 결과를 조사·판단하고 후속 승인을 주도한다.

서버/포트/프록시/보안정책이 바뀌면 같은 단위에서 루트deploy.sh·역할 설치·설정 예제·오프라인 목록·검증/현재 문서를 맞춘다. 신규 설치기 전체를 기존 서버에 실행하지 않는다. 완료한 단위는 표로 보고하고 공개 파일을 자동 커밋/푸시하며 원격 일치를 확인한다. 로컬 대화/검증 원문·업무분담·발표/논문·자격·가중치는 Git 제외다. 실제 운영·공격E2E·새 OS설치·모델 의미 품질을 서로 대체하지 않는다.

OpenClaw·Google Harness²·SSL VPN/모바일 푸시는 후보/검토 범위다. 기본 Qwen3.6-35B-A3B 유지·학습본 승격은 검증 우위 근거가 있을 때만 결정한다. 전체 목표 미완료 상태를 유지하며 예산/시각 때문에 임의 완료나 일시정지로 표시하지 않는다.
