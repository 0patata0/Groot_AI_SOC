## 11/13 재측정·실험: 지연의 실제 원인 (Thor 읽기전용 로그 + 합성 실험)

**가설 정정.** 11/10에는 "3분 모델 상태 점검이 채팅 캐시를 덮어쓴다"고 봤다. 11/13 실험에서 **점검 직후에도 캐시가 유지**됐다(22,009토큰 재요청 0.45초). 이 Ollama 러너는 RAM 프롬프트 캐시(8 GiB, 유휴 슬롯 저장·복원)를 써서 다른 요청이 끼어들어도 이전 대화 상태를 되살린다. 그래서 상태 점검은 바꾸지 않는다.

| 합성 실험(운영 모델, 중립 텍스트, 출력 1토큰) | 시간 |
|---|---|
| 2.2만 토큰 첫 요청(전체 처리) | 20.1초 |
| 같은 프롬프트 재요청 / 상태 점검 직후 / 적재 확인 직후 | 0.36 / 0.45 / 0.39초 |

| 다른 시스템 프롬프트의 봇 끼어듦 → 원래 대화 복귀 | 18.6 → 0.6초 |

**결론 1: 도구 목록이 바뀌면 프롬프트 전체를 다시 처리한다.** Qwen 템플릿은 도구 정의를 시스템 프롬프트 앞부분에 넣고, 이 하이브리드 모델(qwen35moe)은 저장 지점에서만 이어 쓸 수 있기 때문이다. query-completion 플러그인은 조회 호출에서 `tools`를 읽기 도구 일부로 좁히고 `tool_choice`를 바꾼다(후보109 "도구 사전 선정"). 이것이 캐시를 깨서 오히려 느려지게 만든다. 허용 도구 제한은 이미 `valid_tool_names`로 따로 집행된다.

**실제 48시간(5천 토큰 이상 호출 146건)**: 전체 재처리 27건이 824.8초(평균 30.5초), 부분 재처리 44건이 882.4초, 재사용 75건이 232.7초(평균 3.1초)였다. **출력 생성은 2,655.5초**였다(출력 중앙값 763·p90 1,952·최대 4,753토큰, 50.5토큰/초). 중앙값 입력은 37,406토큰이었다.

**결론 2: 출력 생성(긴 추론)이 가장 큰 몫이고, 그다음이 도구 목록 변경에 따른 재처리다.** 대기열 자체보다 호출 하나가 슬롯을 오래 잡는 것이 지연과 병목(#7)의 주원인이다.

개선 방향(미적용):
1. **도구 목록 고정**(정확도 중립 기대): 모든 호출에 같은 전체 도구 목록(같은 순서·바이트)을 보내고, 제한은 `valid_tool_names`·`tool_choice`·지침으로만 한다. 전체·부분 재처리 약 1,700초/48시간(모델 시간의 약 37%)의 대부분을 줄일 수 있다고 본다(추정). 하네스 변경이므로 Harness² 점검→후보 동결→회귀→관리자 경유 적용→새 실제 채팅 검증 절차를 따른다.
2. **추론 강도·출력 상한 조정**(정확도 영향 가능): 도구 선택 단계 등 단순 단계의 추론을 줄인다. 정확성이 속도보다 우선이므로 독립 평가 후에만 적용한다.
3. **추론 서버 분리**(예: 봇별 다른 GPU 서버): 봇 간 대기와 캐시 교체를 없애고 더 빠른 GPU는 호출당 시간도 줄인다. 다만 위 1·2의 단일 호출 비용은 그대로다. DGX는 학습 전용이라는 역할 규칙을 바꾸는 사용자 결정이 필요하다.

DGX를 추론에 쓰려면 다음이 필요하다. 첫째, DGX는 학습, Thor는 추론이라는 역할 규칙을 바꾸는 사용자 결정. 둘째, 10/24 점검에서 DGX는 API만 열린 **공유 서버**였다(다른 모델 상주, 재적재 13초, 출력 22~102토큰/초 변동). 전용 자원과 상주 보장이 없으면 캐시가 사라지고 재적재 비용이 생긴다. 셋째, B→DGX 경로를 A 방화벽에 허용하고 같은 가중치·템플릿을 대조해야 한다. 학습 중에는 GPU를 함께 쓰게 된다.

**도구 목록 고정의 전제(10/24 원칙과의 관계)**: 10/24에는 "권한 경계를 희생해 도구 목록을 고정하지 않는다"고 정했다. 또 Ollama 네이티브 API에는 `tool_choice`가 없다. 따라서 목록을 고정하면 모델이 쓰기 스키마를 보게 된다. 그때도 권한은 `valid_tool_names` 임대(lease)와 디스패치 거부로 계속 집행된다. 다만 모델이 범위 밖 도구를 고르면 거부 후 한 번 더 도는 비용과 정확도 영향이 생길 수 있다. 그래서 이 후보는 사용자 결정과 회귀·실채팅 평가가 필요하다.
