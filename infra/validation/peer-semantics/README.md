# 교차 검토 조건과 표본 범위의 의미 검증

2026-11-14 KST. **수정 후보이며 운영 미적용·품질 미완료**다. 공통 `soc-investigate`의 교차 검토 절만 바꾸는 [후보 파일](candidate-soc-investigate.md)을 준비했다. 현재 canonical 스킬은 관측한 기준본으로 유지하며 신규 설치 경로에도 후보를 승격하지 않았다. [사례](../../hermes/peer-semantics.cases.json) · [출력·판정 원장](validation.json) · [현재 상태](../../../STATUS.md).

## 확인한 문제와 보완

운영의 보존 게시문에서 조건문을 전칭 주장으로 읽고, 상대가 이미 밝힌 전체 건수 미확인을 이견으로 표시한 사례를 확인했다. 공통 스킬에 대상·기간·조건·표본 범위, 권고와 실행의 구분, 기존 한계의 반복 금지, 0건 범위 보존을 명시했다. 정정 시에도 원문에 명시된 조건을 지우지 않게 했다. 안내는 코드에 추가하지 않았고 도구·승인·보호 정책·검증기는 변경하지 않았다.

B 운영 작업자와 기존 비특권 `soc-ollama` 런타임을 그대로 사용하고, 임시 평가 프로세스에서 해당 스킬 절만 교체했다. 실제 모델은 `soc-qwen36:35b-balanced-q4km-20261108`이며 경로는 B 에이전트→Thor다. 입력은 명시적인 합성 조회 영수증으로 실제 MCP 조회가 아니다. R1 6쌍 후 오류 설명을 보완하고 R2 9쌍을 기존/후보 순서 교대로 1회씩 실행했다. 모델 호출 합성 시간은 채팅 왕복·대기열·조회 시간과 다르며 속도 개선률을 주장하지 않는다.

공식 점검 최초 시도는 감사용 색인에서 코드 로딩 스킬 이름을 빠뜨려 실패했다. 실제 workflow routing에 맞게 감사용 색인만 고쳐 재검사했으며 운영 prompt를 바꾼 것이 아니다. 운영 3개 스킬 사본은 기준 SHA `50825f27…`로 일치했다. 후보 일반 조사 본문에는 해당 절이 들어가지 않는다.

## 다음 작업과 배포 경계

조건부 권고를 실제 관측 주장으로 바꾸는 오류와 반복 정정 후 합성 실패를 먼저 보완해야 한다. 구조 검사·104개 회귀 통과만으로 배포하지 않는다. 새로운 실제 MCP·채팅 검증은 아직 하지 않았다. 내부 식별자 제거 후보 `dfc3e2a`는 별도 승인 대기이며 이번 시험에 섞지 않았다. 배포 시 공통 스킬 3사본과 설치 영수증을 현재 SHA에 결속하고 기존 설치 경로를 재사용한다. 자동 배포·운영 모델 변경·공격 시험은 수행하지 않았다.
