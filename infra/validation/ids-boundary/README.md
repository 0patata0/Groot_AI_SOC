## 문제 (11/14 00:01 공동 채널 Hermes 조사)

2차 초안은 판단(`unresolved`)과 상태(`needs_review`)가 일관됐고 제어 줄 서식도 맞았다. 그런데 `unobserved_event_source:suricata` 하나에 걸려 대체 문구로 끝났다. 걸린 두 줄은 Suricata나 IDS를 말하지 않았고, Wazuh 필드명 `sensor_rule_ids`만 썼다. 검사 정규식 `Suricata|IDS`가 대소문자를 무시하고 경계도 없어서 `rule_ids` 안의 "ids"를 IDS 언급으로 읽었다. 이 위반은 새 조회가 필요한 유형이라 두 번째 직접 정정 대상이 아니다. 그래서 오탐 하나로 답변 전체가 대체 문구가 됐다. 23:12에 `10건`의 `0건`을 잘못 읽은 것과 같은 "경계 누락" 계열이다.

검사기에서 센서 이름 약어로 장비를 정하는 정규식을 모두 확인했다.
