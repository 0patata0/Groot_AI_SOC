## 동작과 경계

Native registry가 실제 반환한 읽기마다 도구명·정확한 인자·결과 SHA256·완료 KST를 기록하여 모델에 전달한다. 병렬 호출을 도구 이름만으로 짝짓지 않는다. 원래 결과 전문도 함께 유지하며 원장은 결과나 위험 판단을 대체하지 않는다. `returned`는 반환 완료일 뿐 정상·건강·침해 부재 또는 실제 MCP 전체 경로 성공을 의미하지 않는다. 오류도 구분하며 원장 손상/한도 초과는 미확인으로 남긴다.

모델은 같은 대상·구간을 반복하거나 더 좁히기 전에 이미 확인한 결과와 새로 확인할 사실을 대조한다. 추가 근거가 필요하면 등록 도구를 직접 선택할 수 있다. 수집 공백을 같은 스냅샷 반복으로 해결했다고 주장하지 않으며, 남은 불확실성과 다음 조치를 보고한다. 고정 코드가 위험·종결을 대신 판단하거나 임의로 조사를 끝내지는 않는다.

root 제어기가 완전하다고 확인한 사건의 최초/후속 proposal 참조와 운영자가 직접 적은 ID를 상태조회 선택 규격에 연결한다. 알려진 종류·서버를 유지하고 ID 일부를 임의로 바꾸지 못하게 한다. ID 입력이 없는 상태 도구도 등록과 권한은 유지하며, 모델 화면에 입력 참조가 없다는 사실을 별도로 전달한다. 불완전/과거 형식 문맥은 기존 일반 조회 경로를 유지한다. 이 제한은 사건 재검토의 해당 선택 규격에만 적용하며 일반 채팅의 새로운 ID 조회나 보호 변경 권한을 바꾸지 않는다.

보고 내용 검사도 보완했다. 로그 연속성이 미검증이라는 값만으로 수집 장애·복구 필요를 주장하는 경우와, 실제 같은 IP의 차단 기한 이후 경보 표본을 없다고 서술하는 일부 표현을 검출한다. 다른 센서/다른 IP·공격 성공/침해 영향의 미확인은 구분한다. 이는 관측 사실의 제한된 모순 검사이며 모든 자연어 판단의 정확성 보장이 아니다.

완료된 조회 전체를 인용하도록 이미 정해진 근거 번호는 schema의 고정 배열로 전달한다. 모델이 그 번호를 중복/누락하여 재시도하는 작업을 없애며, 실제 반환되지 않은 근거나 위험 판단을 생성하지 않는다. 번호의 임의 보정으로 잘못된 모델 응답을 성공 처리하지 않는다.
